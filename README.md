## Описание реализованных задач

### 1. Построение пирамиды

- **Восходящий алгоритм (top-down)**  
  Пирамида строится путём последовательного добавления элементов
  с восстановлением свойства кучи после каждой вставки.

- **Нисходящий алгоритм (bottom-up)**  
  Пирамида строится из готового массива путём последовательного
  восстановления свойства кучи, начиная с внутренних вершин.

Для каждого шага выводится текущее состояние пирамиды.

---

### 2. Пирамидальная сортировка

Реализована пирамидальная сортировка для символов слова:

```
SORTING
```

Результат сортировки выводится в алфавитном порядке.

---

### 3. Устойчивость пирамидальной сортировки

В программе явно показано и объяснено, что:

> **Пирамидальная сортировка не является устойчивой**,  
> так как равные элементы в процессе перестановок
> могут менять взаимный порядок.
