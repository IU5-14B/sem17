Отчёт по реализации алгоритмов работы с пирамидой (кучей)

Сравнение восходящего и нисходящего построения пирамиды, а также пирамидальной сортировки

Введение

Данный отчёт описывает реализацию алгоритмов работы с двоичной пирамидой (кучей) на языке C++. Пирамида (heap) — это структура данных, представляющая собой почти полное бинарное дерево, которое удовлетворяет свойству пирамиды: для max-heap значение в каждом узле не меньше значений в его потомках.

В реализации представлены два метода построения пирамиды (сверху вниз и снизу вверх), а также алгоритм пирамидальной сортировки (heapsort) для символов.

Структура проекта

Проект состоит из трёх файлов:

heap.h
#pragma once #include <vector> #include <string> void buildHeapTopDown(std::vector<int> data); void buildHeapBottomUp(std::vector<int> data); void heapSortChars(const std::string& word);
heap.cpp
// Содержит реализации функций объявленных в heap.h // Включает вспомогательные функции siftUp и siftDown // Реализует построение пирамиды двумя способами и пирамидальную сортировку
main.cpp
#include "heap.h" #include <iostream> int main() { std::vector<int> data = {1, 8, 6, 5, 3, 7, 4}; buildHeapTopDown(data); std::cout << std::endl; buildHeapBottomUp(data); std::cout << std::endl; heapSortChars("SORTING"); std::cout << std::endl; std::cout << "Пирамидальная сортировка не является устойчивой: " << "равные элементы могут менять взаимный порядок." << std::endl; return 0; }

Вспомогательные функции

Функция siftUp (просеивание вверх)

Функция siftUp восстанавливает свойство пирамиды, перемещая элемент вверх по дереву, пока он не станет меньше своего родителя (для max-heap). Используется при добавлении нового элемента в пирамиду.

Принцип работы: Сравниваем элемент с родителем. Если элемент больше родителя, меняем их местами. Повторяем, пока элемент не займёт правильную позицию или не достигнет корня.

static void siftUp(std::vector<int>& a, int i) { while (i > 0) { int p = (i - 1) / 2; if (a[p] >= a[i]) break; std::swap(a[p], a[i]); i = p; } }

Функция siftDown (просеивание вниз)

Функция siftDown восстанавливает свойство пирамиды, перемещая элемент вниз по дереву, пока он не станет больше своих потомков (для max-heap). Используется при удалении корневого элемента или построении пирамиды снизу вверх.

Принцип работы: Сравниваем элемент с левым и правым потомками. Если один из потомков больше элемента, меняем местами с наибольшим потомком. Повторяем, пока элемент не займёт правильную позицию.

static void siftDown(std::vector<int>& a, int i, int n) { while (true) { int l = 2 * i + 1; int r = 2 * i + 2; int largest = i; if (l < n && a[l] > a[largest]) largest = l; if (r < n && a[r] > a[largest]) largest = r; if (largest == i) break; std::swap(a[i], a[largest]); i = largest; } }

Алгоритмы построения пирамиды

Восходящее построение (сверху вниз)

Алгоритм построения пирамиды сверху вниз последовательно добавляет элементы в конец пирамиды и восстанавливает свойство пирамиды с помощью siftUp.

Шаги алгоритма:

  1. Начинаем с пустой пирамиды
  2. Для каждого элемента исходного массива:
    • Добавляем элемент в конец пирамиды
    • Вызываем siftUp для нового элемента
    • Выводим текущее состояние пирамиды
void buildHeapTopDown(std::vector<int> data) { std::cout << "Восходящее построение пирамиды (алгоритм сверху вниз):" << std::endl; std::vector<int> heap; for (int x : data) { heap.push_back(x); siftUp(heap, (int)heap.size() - 1); print(heap); // выводим состояние пирамиды после каждой вставки } }

Нисходящее построение (снизу вверх)

Алгоритм построения пирамиды снизу вверх преобразует исходный массив в пирамиду, начиная с последних элементов, имеющих потомков, и применяя siftDown.

Шаги алгоритма:

  1. Выводим исходный массив
  2. Начинаем с последнего элемента, имеющего потомков (индекс n/2 - 1)
  3. Для каждого элемента от n/2 - 1 до 0:
    • Вызываем siftDown для текущего элемента
    • Выводим состояние массива после каждого siftDown
void buildHeapBottomUp(std::vector<int> data) { std::cout << "Нисходящее построение пирамиды (алгоритм снизу вверх):" << std::endl; print(data); // исходный массив for (int i = (int)data.size() / 2 - 1; i >= 0; --i) { siftDown(data, i, (int)data.size()); print(data); // выводим состояние после каждого siftDown if (i == 0) break; // чтобы не уйти в бесконечный цикл при i-- (для int) } }

Пирамидальная сортировка (heapsort)

Алгоритм пирамидальной сортировки использует структуру данных "пирамида" для сортировки элементов. Алгоритм состоит из двух этапов:

  1. Построение max-heap из исходного массива
  2. Извлечение элементов из пирамиды:
    • Меняем местами корень (максимальный элемент) с последним элементом
    • Уменьшаем размер пирамиды на 1
    • Восстанавливаем свойство пирамиды для нового корня с помощью siftDown
    • Повторяем, пока в пирамиде не останется 1 элемент
void heapSortChars(const std::string& word) { std::vector<char> a(word.begin(), word.end()); int n = (int)a.size(); // строим max-heap for (int i = n / 2 - 1; i >= 0; --i) { int j = i; while (true) { int l = 2 * j + 1; int r = 2 * j + 2; int largest = j; if (l < n && a[l] > a[largest]) largest = l; if (r < n && a[r] > a[largest]) largest = r; if (largest == j) break; std::swap(a[j], a[largest]); j = largest; } if (i == 0) break; } // сортировка: переносим максимум в конец и восстанавливаем кучу for (int i = n - 1; i > 0; --i) { std::swap(a[0], a[i]); int j = 0; while (true) { int l = 2 * j + 1; int r = 2 * j + 2; int largest = j; if (l < i && a[l] > a[largest]) largest = l; if (r < i && a[r] > a[largest]) largest = r; if (largest == j) break; std::swap(a[j], a[largest]); j = largest; } } std::cout << "Результат пирамидальной сортировки: "; for (char c : a) std::cout << c << " "; std::cout << std::endl; }

Примечание: В реализации пирамидальной сортировки для символов используется встроенная реализация siftDown (без вызова отдельной функции), чтобы продемонстрировать алгоритм в одном месте.

Характеристики пирамидальной сортировки

Характеристика Значение

Результаты выполнения программы

Входные данные

Исходный массив: {1, 8, 6, 5, 3, 7, 4} Строка для сортировки: "SORTING"

Ожидаемый вывод программы

Восходящее построение пирамиды (алгоритм сверху вниз): 1 8 1 8 1 6 8 5 6 1 8 5 6 1 3 8 5 7 1 3 6 8 5 7 4 3 6 1 Нисходящее построение пирамиды (алгоритм снизу вверх): 1 8 6 5 3 7 4 1 8 7 5 3 6 4 8 1 7 5 3 6 4 8 5 7 1 3 6 4 Результат пирамидальной сортировки: G I N O R S T Пирамидальная сортировка не является устойчивой: равные элементы могут менять взаимный порядок.

Пояснение к выводу: В восходящем построении после каждой вставки элемента выводится текущее состояние пирамиды. В нисходящем построении выводится состояние после каждого вызова siftDown. Пирамидальная сортировка выводит символы в алфавитном порядке (по возрастанию кодов ASCII).

Выводы

1. Алгоритмы построения пирамиды: Нисходящий алгоритм (снизу вверх) является более эффективным с точки зрения временной сложности (O(n) против O(n log n) у восходящего), а также работает на месте, не требуя дополнительной памяти.

2. Пирамидальная сортировка: Представляет собой эффективный алгоритм сортировки со сложностью O(n log n) в худшем случае и работающий на месте (O(1) дополнительной памяти).

3. Неустойчивость: Пирамидальная сортировка не является устойчивой, что означает, что равные элементы могут изменить свой относительный порядок в отсортированной последовательности.

4. Практическое применение: Пирамиды используются не только для сортировки, но и для реализации приоритетных очередей, алгоритма Дейкстры, и других алгоритмов, где требуется быстрый доступ к элементу с наивысшим приоритетом.
